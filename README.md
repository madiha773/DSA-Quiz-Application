# DSA Quiz Application

A quiz application written in C++ that shows practical use of Data Structures and Algorithms.

## Features
- Login with a username and password
- Attempt a multiple-choice quiz
- Get instant feedback after each answer
- See your final score at the end

## Concepts Used
- Stack (LIFO)
- Queue (FIFO)

## Built With
- C++

## My Role
This was a group project. My part was designing the quiz questions
